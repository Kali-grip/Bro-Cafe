# Bro-Cafe ☕

Bro-Cafe is a food and café-themed website created as part of a Git and GitHub tutorial project. The main purpose of this project was to practice the fundamentals of web development while also learning how to use Git for version control and manage a project using GitHub.

The website represents a modern café/food website where users can explore different food items, learn more about the café, and get a simple idea of the services and experience offered by the brand.

## 🚀 Project Overview

Bro-Cafe was developed as a beginner-friendly web development project. While building this website, I focused not only on creating the frontend interface but also on understanding how Git works in a real development workflow.

This project helped me practice important concepts such as:

- Creating and organizing a web project
- Writing HTML, CSS, and JavaScript
- Managing files and folders
- Initializing a Git repository
- Tracking changes with Git
- Creating commits
- Working with branches
- Connecting a local repository to GitHub
- Pushing changes to a remote repository
- Maintaining a project using version control

## 🎯 Purpose of the Project

The primary goal of Bro-Cafe was to learn and practice Git while working on a practical website.

Instead of learning Git only through commands and theory, I used a real website project to understand how developers use version control during development.

Through this project, I learned how to:

1. Create a project repository.
2. Track changes made to the project.
3. Save different versions of the project using commits.
4. Understand the basic Git workflow.
5. Connect a local project with GitHub.
6. Push project files to a remote repository.
7. Make changes and update the repository.
8. Understand how Git can be used for collaborative development.

## 🛠️ Technologies Used

The project was created using common web technologies:

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used for styling, layout, colors, spacing, and overall visual appearance.
- **JavaScript** – Used to add interactivity and dynamic behavior where required.
- **Git** – Used for version control and tracking project changes.
- **GitHub** – Used to host and manage the Git repository remotely.
